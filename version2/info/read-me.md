# Advanced AdBlocker Extension

A powerful browser extension designed to block ads, protect your privacy, and enhance security online. This extension gives users full control over their online privacy with features like VPN spoofing, DNS leak protection, advanced fingerprint protection, and more.

## Features

- **Advanced Ad Blocking:** Block ads and trackers across all websites.
- **DNS Leak Protection:** Prevent your DNS information from leaking to external servers using DNS-over-HTTPS (DoH) or DNS-over-TLS (DoT).
- **Fingerprint Protection:** Spoof your browser fingerprint (e.g., screen resolution, user agent, WebRTC).
- **Geo-Spoofing:** Fake your geographical location to hide your real position.
- **Web Request Blocking:** Block malicious web requests and unwanted traffic.
- **Google/Chrome Data Blocking:** Block Google and other tracking services from collecting user data.
- **End-to-End Encryption:** Encrypt user data for enhanced security.

## Installation

1. Download and extract the extension from GitHub.
2. Go to `chrome://extensions` in your browser.
3. Enable **Developer mode** in the top right corner.
4. Click on **Load unpacked**.
5. Select the folder containing the extension and click **Open**.

The extension should now be installed and activated in your browser!

### For Brave Browser:

Brave supports Chrome extensions, so you can follow the same installation steps as for Chrome.

## Usage

- Once the extension is installed, it will automatically block ads and trackers.
- To adjust settings, click on the extension icon in your browser's toolbar and open the settings page.
- You can enable/disable specific features like VPN spoofing, DNS leak protection, and geo-spoofing directly from the settings panel.

## Features in Detail

### VPN Spoofing
Change your IP address and mask your real geographical location when the extension is active.
 

### DNS Leak Protection
Secure your DNS by using DNS-over-HTTPS (DoH) or DNS-over-TLS (DoT) to prevent DNS leaks.

### Fingerprint Protection
Spoof browser and device information, including screen resolution, user agent, and font detection.

### Geo-Spoofing
Fake your geographic location to hide your real position.

### Web Request Blocking
Block malicious web requests, including tracking services like Google Analytics and other unwanted scripts.

## Privacy & Security

All settings are securely stored using AES-GCM encryption. Your user data is stored locally, and no personal information is sent to external servers.
